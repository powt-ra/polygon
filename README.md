# Python Polygon Art

Object-oriented turtle graphics: a `Polygon` class that draws regular polygons.

## Files

- `polygon_shape.py` - the `Polygon` class
- `05_polygon_art_starter.py` - static artwork (20 polygons)
- `06_animated_polygon_art_starter.py` - animated artwork

## How to run

Requires Python 3 with Tkinter and a graphical desktop.

    python 05_polygon_art_starter.py
    python 06_animated_polygon_art_starter.py
